Atividade Java Web

Inventário simples, escopo claro.

Sistema acadêmico para cadastrar laboratórios e seus equipamentos, desenvolvido com Servlets, JPA/Hibernate, H2 e uma interface responsiva em Bootstrap.

Conhecer o projetoAbrir repositório

Objetivo

Resolver exatamente o que a atividade pede.

O Inventory-IT demonstra um fluxo completo de aplicação web Java: formulários no navegador, processamento por Servlets, persistência com DAOs e JPA/Hibernate e armazenamento em H2. A implementação foi reduzida ao essencial para tornar o código fácil de apresentar e avaliar.

Funcionalidades

O núcleo do inventário

01

Cadastrar laboratórios

Registra nome e bloco de cada laboratório.

02

Listar laboratórios

Apresenta os ambientes cadastrados em uma tabela direta.

03

Cadastrar equipamentos

Registra tipo, número de série e laboratório selecionado.

04

Exibir associação

Mostra cada equipamento junto do laboratório relacionado.

Simplificação

Menos recursos, mais clareza.

A versão final mantém somente cadastro e listagem. Edição, exclusão, filtros, pesquisa e regras extras foram removidos. O Maven gerencia as dependências, os DAOs usam try-with-resources e as gravações preservam o rollback quando necessário.
